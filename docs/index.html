Simulateur « et si ? » – modèles A et B

Partez de la situation réelle du dernier mois consolidé d'un pays, puis modifiez les cas, la couverture vaccinale ou la vulnérabilité : les deux modèles recalculent la probabilité de flambée dans les 3 mois suivants. Les calculs sont faits dans votre navigateur.

Probabilité de flambée (mois t+1 à t+3)

Modèle A : régression logistique, interprétable. Modèle B : XGBoost (500 arbres). Ensemble : moyenne des deux ; l'alerte se déclenche au-dessus du seuil de l'ensemble. Une alerte appelle une vérification des données et une vigilance renforcée, pas une riposte automatique.

Districts et localités

Limites infranationales des 54 pays : régions (ADM1), districts (ADM2), communes (ADM3), localités administratives (ADM4) selon les pays (geoBoundaries, limites humanitaires OCHA COD-AB en priorité), villes et villages de plus de 1 000 habitants (GeoNames). Vous pouvez aussi importer vos propres limites (zones ou aires de santé, en KML ou GeoJSON). Les fichiers KML sont générés dans votre navigateur.

Performance des modèles

Validation temporelle : apprentissage sur 2013-2022, test sur 2023-2026 (années jamais vues par les modèles). Cible : flambée dans les 3 mois.

Stabilité dans le temps (origine glissante)

Pour chaque année, le modèle apprend sur les années précédentes puis prédit l'année. 0,5 = hasard, 1 = parfait.

Modèle B – variables les plus utiles

Part du gain total apporté par chaque variable dans les arbres de décision.

Modèle A – odds ratios par écart-type

OR > 1 : le facteur augmente le risque de flambée ; OR < 1 : il le diminue. « Par écart-type » permet de comparer des facteurs d'unités différentes. Coefficients du modèle final, réentraîné sur toutes les données (le rapport présente ceux du modèle d'apprentissage 2013-2022).

Méthode en bref

Données : surveillance mensuelle provisoire de l'OMS (cas cliniques, épi-liés et confirmés), couverture vaccinale WUENIC (MCV1, MCV2), indicateurs de la Banque mondiale, limites geoBoundaries (KML). Flambée : mois où les cas dépassent max(10 ; moyenne + 2 écarts-types des 24 mois précédents). IVR : indice composite 0-100 (déficit vaccinal 35 %, accès aux soins 20 %, démographie, pauvreté, malnutrition 15 % chacun). Modèle A : régression logistique (+ binomiale négative pour les comptes). Modèle B : XGBoost. Validation temporelle 2023-2026 : AUC 0,82 (A), 0,84 (B), 0,84 (ensemble).

Outil de recherche : il ne remplace ni l'investigation de terrain ni le jugement des autorités sanitaires. Pour les chercheurs : le code Python (réentraînement, ligne de commande) est sur GitHub.
